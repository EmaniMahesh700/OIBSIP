# WebNova - Modern Landing Page

## OASIS INFOBYTE Internship

**Track:** Web Development & Designing  
**Level:** Level 1  
**Task:** Task 1 - Landing Page

---

## Project Overview

WebNova is a modern and responsive landing page developed as part of the OASIS INFOBYTE Web Development & Designing Internship.

The project demonstrates the use of HTML5 and CSS3 to create a clean, professional, user-friendly, and responsive website.

---

## Objective

The objective of this task is to create a responsive landing page with a clear navigation structure, hero section, content sections, call-to-action elements, and footer.

The website is designed to work properly on desktop, tablet, and mobile screen sizes.

---

- CSS Media Queries
- Responsive Web Design

## Website Sections

### 1. Navigation Bar

The navigation bar provides links to the main sections of the website:

- Home
- Features
- About
- Contact

The navigation bar remains visible while scrolling.

### 2. Hero Section

The hero section introduces WebNova with the headline:

**Build Your Digital Future**

It also contains a short description and an **Explore More** button.

### 3. Features Section

The Features section presents three main features:

- Modern Design
- Responsive Layout
- Fast Performance

### 4. About Section

The About section explains the purpose of WebNova and focuses on creating modern and user-friendly digital experiences.

### 5. Call-to-Action Section

The Call-to-Action section encourages users to start a new project and contact the service.

### 6. Contact Section

The Contact section provides an option for users to get in touch through email.

### 7. Footer

The footer contains the WebNova description, navigation links, and copyright information.

---

## Responsive Design

The website is designed to adapt to different screen sizes.

Responsive CSS media queries are used to adjust:

- Navigation layout
- Font sizes
- Feature cards
- About section
- Footer layout
- Spacing and alignment

The website has been tested on both desktop and mobile screen sizes.

## How to Run the Project

### Method 1 - Using Live Server

1. Open the project in Visual Studio Code.
2. Open `index.html`.
3. Right-click inside the HTML file.
4. Select **Open with Live Server**.
5. The website will open in your web browser.

### Method 2 - Directly in Browser

1. Open the project folder.
2. Double-click `index.html`.
3. The website will open in your default browser.
