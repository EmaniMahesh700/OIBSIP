# Task 3: Temperature Converter Website

An interactive temperature converter application built as part of the **Oasis Infobyte Web Development & Designing Internship (Level 1)**.

## 📌 Project Overview
This web application allows users to enter a temperature value and choose its unit (Celsius, Fahrenheit, or Kelvin) to convert it accurately across multiple temperature scales with real-time feedback and validation.

## ✨ Features
* **Multi-Unit Support:** Converts seamlessly between Celsius, Fahrenheit, and Kelvin.
* **Input Validation:** Prevents empty or invalid inputs with clear error messages.
* **Modern Dark UI:** Styled with a glassmorphism card layout, vibrant gradients, and clean typography.
* **Responsive Layout:** Works smoothly across desktop and mobile screens.

## 🛠️ Tech Stack
* **HTML5:** Semantic form inputs and card layout.
* **CSS3:** Custom styles, CSS variables, and modern dark styling.
* **JavaScript (ES6):** Real-time calculation logic and DOM manipulation.
