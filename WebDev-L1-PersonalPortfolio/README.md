## Project Overview

This project is a personal portfolio website created to introduce my background, showcase my technical skills and projects, and provide contact information.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Responsive Web Design

## Features

- Navigation bar with section links
- Introduction and hero section
- Profile image
- About Me section
- Skills section
- Project cards
- Contact section
- Responsive design for mobile devices
- Smooth scrolling

## Project Structure

```text
WebDev-L1-PersonalPortfolio/
├── index.html
├── style.css
├── README.md
└── screenshots/
```

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.
4. View the portfolio in your browser.

## Testing

The portfolio should be checked on desktop and mobile screen sizes. Navigation links, project cards, profile image, and contact link should be tested.
